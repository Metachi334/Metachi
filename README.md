# Metachi 🧠💚⚡

**Public Health • Mental Health • Web3 Educator Agent**  
Powered by **Binance Agent OS (MCP)**

Metachi is a no-code AI agent that acts as your personal **Content Manager, Strategist & Creative**.  
It bridges mental/public health education with Web3 & crypto markets — helping creators and traders stay informed, balanced, and emotionally resilient while navigating volatile markets.

Inspired by anime aesthetics, wellness culture, and the desire to humanize crypto.

---

## ✨ Core Capabilities

- Live market data via Binance MCP (BNB, BTC, ETH + more)
- Agentic sub-account balance checks
- Daily content creation (X/Twitter posts, threads, video scripts)
- Monthly performance & wellness reports
- Market analysis with mental-health framing
- Portfolio insights + risk-awareness messaging
- Educational content that supports healthier trading habits

---

## 🛠 Tech Stack (No-Code Friendly)

- **ChatGPT** (web) + Developer Mode / Plugins
- **Binance Agent OS MCP Server**: `https://agent.binance.com/mcp/agentic`
- Agentic Sub-Account (isolated, no withdrawal permissions)

---

## 🚀 Quick Start (ChatGPT No-Code)

1. Log into Binance (desktop) and ChatGPT (web).
2. Enable Developer Mode in ChatGPT.
3. Add the Binance MCP plugin using the official endpoint.
4. Authenticate and grant only the scopes you need (Market Data + Account recommended to start).
5. Fund your Agentic Sub-Account with only the amount you’re comfortable letting the agent see/use.
6. Paste the Metachi system prompt and start chatting.

Full step-by-step guide is below.

---

```text
You are Metachi — a warm, insightful, anime-inspired Public Health, Mental Health & Web3 Educator AI agent. You act as my Content Manager, Strategist, and Creative partner.

Your core mission:
- Educate people about mental health, public health, and emotional resilience in the context of Web3 and crypto trading.

- Calm, supportive, slightly playful with light anime flair (think wise companion energy).

Default daily request format:
- Short X post (under 280 characters preferred, or thread-ready)
