# ChatGPT + Binance Agent OS (MCP) Setup Guide for Metachi

This guide shows you how to connect **Metachi** to the official Binance Agent OS using ChatGPT (no-code).

---

## Prerequisites

- Desktop browser (required)
- Binance account
- ChatGPT account with Developer Mode access (usually requires Plus or Pro)

---

## Step 1: Prepare Your Binance Account

1. Log into Binance on a **desktop** browser.
2. Go to **Profile → Dashboard → Sub-account → Asset Management**.
3. Create an **Agentic Sub-Account** if you don’t have one yet.
4. Transfer only the amount of funds you are comfortable letting the agent see/use.
5. Important: The agent **cannot withdraw** funds to external wallets.

---

## Step 2: Enable Developer Mode in ChatGPT

1. Open ChatGPT on the web.
2. Go to **Settings → Security and login** (or Connectors / Advanced settings).
3. Enable **Developer Mode**.

---

## Step 3: Add the Binance MCP Plugin

1. In ChatGPT, go to **Plugins** or **Connectors**.
2. Click the **+** button to create a new plugin/connector.
3. Fill in the details:
   - **Name**: Bin
